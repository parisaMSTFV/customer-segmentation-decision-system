# Data

Every row in this repository is synthetic and generated by `src/customer_segmentation/synthetic.py` with seed `42`. The public snapshot date is `2026-01-01` and is part of the versioned input contract.

- `synthetic/customer_features.csv` contains the observations available to the model.
- `synthetic/evaluator_truth.csv` contains planted persona labels used only after fitting for benchmark evaluation.
- `processed/split_assignments.csv` records the development/holdout boundary.
- `processed/customer_segments.csv` contains model assignments and no evaluator truth.

The data does not represent real people, customers, orders, internal schemas, or company performance. It is suitable for testing the public workflow, not for estimating expected production accuracy.

User-supplied feature CSVs are read from the path passed to `customer-segmentation fit` or `score`; they are not copied into this directory. Generated `artifacts/` are Git-ignored. See the [external input contract](../docs/INPUT_SCHEMA.md).
